# 企業級 YARA 集成殺毒軟件 - 完整實現指南

## 項目概述

這是一個企業級的 Rust + YARA 殺毒軟件，集成以下功能：

✅ **YARA 規則引擎** - 基於已編譯的 27.4MB anti.yarac 規則
✅ **文件監控** - 實時掃描新建和修改的文件
✅ **記憶體監控** - 進程記憶體和映像載入檢測
✅ **隔離機制** - 自動隔離和恢復感染文件
✅ **進程通訊** - Named Pipe IPC + 驅動通訊
✅ **GUI 界面** - egui 實時監控面板
✅ **企業功能** - 日誌、報告、白名單管理

## 快速開始

### 第 1 步：編譯 YARA C 庫

在 PowerShell（管理員模式）中運行：

```powershell
# 進入專案目錄
cd rust_antivirus

# 運行編譯腳本（使用 Visual Studio 2022, x64, Release）
.\build_yara.ps1 -Architecture x64 -VSVersion 2022 -Configuration Release

# 如果遇到權限問題
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\build_yara.ps1
```

**編譯會生成：**
- `third_party\yara\lib\x64\Release\yara.lib` (2-3MB 靜態庫)
- `third_party\yara\include\yara\*.h` (所有頭文件)

### 第 2 步：編譯 Rust 程序

```bash
# 進入項目目錄
cd rust_antivirus

# 編譯（會自動使用 build.rs 連結 YARA 庫）
cargo build --release

# 或帶日誌輸出
RUST_LOG=info cargo build --release
```

**輸出文件：**
- `target\release\wenle-antivirus.exe` - 主程序
- `target\release\file-monitor.exe` - 文件監控
- `target\release\memory-monitor.exe` - 記憶體監控

### 第 3 步：運行程序

```bash
# 運行主程序（GUI + 掃描服務）
cargo run --release

# 或直接執行
.\target\release\wenle-antivirus.exe

# 運行 YARA 掃描示例
cargo run --bin yara_scan_example --release
```

## 核心技術架構

### 1. YARA FFI 集成層 (yara_sys.rs)

定義 YARA C API 的 Rust 綁定：

```rust
extern "C" {
    pub fn yr_initialize() -> c_int;
    pub fn yr_rules_load(filename: *const c_char, rules: *mut *mut YR_RULES) -> c_int;
    pub fn yr_rules_scan_mem(...) -> c_int;
    pub fn yr_rules_destroy(rules: *mut YR_RULES) -> c_int;
}
```

### 2. 高級引擎層 (yara_engine.rs)

- **全局單一初始化**：確保 YARA 只初始化一次
- **線程安全掃描**：使用 Arc<Mutex> 共享規則
- **自動資源清理**：實現 Drop 特徵

```rust
// 初始化
YaraEngine::init()?;

// 加載規則
let engine = YaraEngine::with_rules("Configuration/anti.yarac")?;

// 掃描
let result = engine.scan_mem(&buffer)?;
```

### 3. 集成層 (yara_integration.rs)

提供高級 API：

- **FileScanner** - 單文件/目錄掃描
- **MemoryScanner** - 進程記憶體掃描（Windows）
- **QuarantineManager** - 隔離和恢復

```rust
let scanner = FileScanner::new(engine);
let result = scanner.scan_file("target.exe")?;
scanner.scan_directory("C:\\Windows")? ;

let quarantine = QuarantineManager::new(Path::new("Quarantine"))?;
quarantine.quarantine_file(&file_path, "Win32.Trojan")?;
```

## YARA 規則使用

### 已編譯規則

你現有的 `Configuration/anti.yarac` 包含：

- **PE 分析**：導入表、節、簽名檢查
- **行為檢測**：注冊表、文件操作、進程創建
- **簽名檢測**：已知惡意軟件哈希
- **啟發式**：可疑 API 調用、加殼檢測

### 加載和使用

```rust
// 加載編譯的規則（快速，二進制格式）
let engine = YaraEngine::with_rules("Configuration/anti.yarac")?;

// 掃描文件
let result = engine.scan_file("unknown.exe")?;

// 檢查匹配
for rule in result.matched_rules {
    println!("Matched: {}", rule.rule_name);
}
```

### 規則更新流程

1. 修改/更新 YARA 規則文本（.yar）
2. 使用 yarac64.exe 編譯：
   ```bash
   Configuration\yarac64.exe rules.yar rules.yarac
   ```
3. 替換 `Configuration/anti.yarac`
4. 重新啟動掃描服務

## Windows 驅動集成架構

### 推薦架構

```
┌─────────────────────┐
│  File System Events │
└──────────┬──────────┘
           │
      ┌────▼──────┐
      │   Kernel  │
      │  Minifilter│ Intercepts: Create/Write/Delete
      │   Driver  │
      └────┬──────┘
           │ IOCTL/DeviceIoControl
      ┌────▼──────────────────────┐
      │  User-mode Scanner Service │
      │  (Windows Service)         │
      │  ┌────────────────────┐    │
      │  │  YaraEngine        │    │
      │  │  FileScanner       │    │
      │  │  QuarantineManager │    │
      │  └────────────────────┘    │
      └──────┬─────────────────────┘
             │ Results
      ┌──────▼──────┐
      │  Kernel     │
      │  (Allow/Block)
      └─────────────┘
```

### 驅動集成步驟

1. **File System Minifilter** (C++ 或 Rust WinDriver)
   ```cpp
   FltCreateFilter(); // 創建過濾器
   FltRegisterFilter(); // 註冊過濾器
   FltRegisterCommunicationPort(); // 創建通訊端口
   ```

2. **用戶態通訊服務** (Rust)
   ```rust
   // 接收驅動事件
   while let Some(event) = receive_from_driver() {
       // 掃描
       let result = scanner.scan_file(&event.path)?;
       // 回傳結果
       send_to_driver(result)?;
   }
   ```

3. **驅動簽章** (生產環境)
   ```powershell
   # Windows Driver Kit (WDK)
   SignTool sign /f certificate.pfx driver.sys
   ```

## 文件監控流程

### 架構

```
主程序 (GUI)
    │
    ├─► File Monitor (獨立進程)
    │       │ WatchDir/RegexFilter
    │       ├─► 檢測新文件
    │       └─► 通知掃描引擎 (IPC)
    │
    ├─► Memory Monitor (獨立進程)
    │       │ ProcessNotify
    │       ├─► 檢測新進程
    │       └─► 掃描記憶體 (IPC)
    │
    └─► Scan Engine (主線程)
            │ YARA 掃描
            ├─► 文件掃描
            ├─► 記憶體掃描
            └─► 隔離操作
```

### 配置

在 `config/mod.rs` 中設定：

```rust
pub struct MonitorConfig {
    pub enabled: bool,
    pub scan_delay_ms: u64,
    pub quarantine_enabled: bool,
    pub auto_delete: bool,
    pub log_path: PathBuf,
}
```

## 記憶體掃描

### 支援平台

- ✅ **Windows x64** - 完整支持
- ⚠️ **Windows x86** - 有限支持
- ❌ **Linux/macOS** - 不支持

### 記憶體掃描方法

```rust
// 掃描進程記憶體（Windows 特定）
unsafe {
    let handle = OpenProcess(PROCESS_VM_READ, 0, pid);
    ReadProcessMemory(handle, address, buffer.as_mut_ptr(), size, &mut read);
    
    // 使用 YARA 掃描
    let result = engine.scan_mem(&buffer)?;
}
```

### 掃描目標

1. **代碼段** (0x400000+)
2. **堆內存** (可配置)
3. **DLL 映像** (模塊列表)

## 性能優化

### 1. 規則預編譯

- **文本規則**（.yar）：每次掃描需要解析
- **編譯規則**（.yarac）：直接使用，速度快 3-5 倍

你已有 `anti.yarac`，使用它可獲得最佳性能。

### 2. 記憶體映射 I/O

對大文件：

```rust
// 不要一次讀取整個文件
let chunk_size = 4 * 1024 * 1024; // 4MB
for chunk in file_chunks(chunk_size) {
    engine.scan_mem(&chunk)?;
}
```

### 3. 並行掃描

```rust
use rayon::prelude::*;

results: Vec<_> = files
    .par_iter()
    .map(|file| scanner.scan_file(file))
    .collect();
```

### 4. 白名單優化

緩存已掃描文件的哈希，跳過重複掃描。

## 故障排除

### 編譯問題

**問題 1：找不到 YARA 源碼**
```
CMake Error: yara-4.5.5 not found
```
**解決：**
```bash
git clone https://github.com/VirusTotal/yara.git third_party\yara\yara-4.5.5
```

**問題 2：Visual Studio 路徑錯誤**
```
The system cannot find the path specified.
```
**解決：**
```powershell
.\build_yara.ps1 -VSVersion 2022 # 使用完整版本號
```

**問題 3：連結錯誤**
```
error LNK2001: unresolved external symbol yr_initialize
```
**解決：**
檢查 `third_party\yara\lib\x64\Release\yara.lib` 是否存在

### 運行時問題

**問題 1：無法加載規則**
```
Error: Failed to load YARA rules
```
**解決：**
檢查 `Configuration/anti.yarac` 路徑和權限

**問題 2：記憶體掃描失敗**
```
Error: Cannot open process
```
**解決：**
以管理員身份運行，確保有 PROCESS_VM_READ 權限
