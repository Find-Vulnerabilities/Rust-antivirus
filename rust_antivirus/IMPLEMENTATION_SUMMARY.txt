核心模塊（src/）
─────────────

yara_sys.rs
  作用：YARA C API 的 Rust FFI 綁定
  關鍵函數：yr_initialize, yr_rules_load, yr_rules_scan_mem
  用途：底層 C 庫調用

yara_engine.rs
  作用：YARA 引擎的高級安全封裝
  關鍵特性：
    - 全局單一初始化
    - 線程安全（Arc<Mutex>）
    - 自動資源清理（Drop）
  用途：在應用中安全使用 YARA

yara_integration.rs
  作用：高級掃描和隔離 API
  提供的類：
    - FileScanner - 文件掃描
    - MemoryScanner - 記憶體掃描（Windows）
    - QuarantineManager - 隔離管理
  用途：業務邏輯層

yara_integration_helpers.rs
  作用：集成到現有 engine.rs 的輔助函數
  提供的類：
    - YaraIntegrationHelper - 簡化的掃描接口
  用途：簡化 YARA 集成

build_yara.ps1

# ============================================================================
# 編譯和使用建議
# ============================================================================

推薦編譯順序：
────────────

1. 驗證環境
   - Visual Studio 2022（含 C++ 工具）
   - CMake 3.15+
   - Rust 1.70+
   
2. 編譯 YARA（第一次）
   .\build_yara.ps1
   
3. 編譯 Rust
   cargo clean
   cargo build --release
   
4. 測試
   cargo run --bin yara_scan_example --release
   
5. 部署
   複製 target\release\*.exe 和 Configuration\anti.yarac


常用命令：
────────

# 快速重新編譯
cargo build --release

# 帶日誌編譯
RUST_LOG=info cargo build --release

# 運行主程序
cargo run --release

# 運行掃描示例
cargo run --bin yara_scan_example --release

# 代碼檢查
cargo clippy

# 格式檢查
cargo fmt --check

# 單元測試
cargo test


YARA 規則使用：
──────────────

1. 預編譯規則（推薦）
   - 使用現有 Configuration/anti.yarac
   - 27.4MB 編譯規則集
   - 加載快速，掃描高效

2. 更新規則
   - 編輯原始規則文件（.yar）
   - 使用 Configuration/yarac64.exe 編譯
     yarac64.exe rules.yar rules.yarac
   - 替換 Configuration/anti.yarac

3. 加載規則代碼
   let engine = YaraEngine::with_rules("Configuration/anti.yarac")?;
   let result = engine.scan_file("target.exe")?;


性能優化建議：
────────────

1. 使用編譯規則（.yarac）- 比文本規則快 3-5 倍
2. 並行掃描 - 使用 rayon 庫並行處理
3. 分片掃描 - 大文件分 4MB 片段掃描
4. 白名單緩存 - 避免重複掃描
5. 記憶體映射 - 對大文件使用 mmap

# ============================================================================
# 遇到問題？檢查清單
# ============================================================================

編譯失敗
───────
1. 檢查 Visual Studio 是否已安裝
2. 驗證 YARA 源碼在正確位置
3. 運行 build_yara.ps1 重新編譯
4. 清潔編譯：cargo clean && cargo build

規則加載失敗
──────────
1. 驗證 anti.yarac 存在且大小為 27.4MB
2. 檢查文件路徑和權限
3. 嘗試絕對路徑而非相對路徑
4. 檢查磁盤空間充足

記憶體掃描失敗
────────────
1. 以管理員身份運行程序
2. 檢查目標進程是否存在
3. 驗證 PROCESS_VM_READ 權限
4. 在 Windows Defender 中排除此程序

掃描速度慢
────────
1. 確保使用 .yarac 編譯規則
2. 考慮分片掃描大文件
3. 啟用並行掃描（rayon）
4. 優化規則（移除低優先級規則）
