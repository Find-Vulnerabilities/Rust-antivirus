## 編譯步驟（完整流程）

### 1️⃣ 準備環境

**系統要求：**
- Windows 10/11 或 Windows Server 2019+
- Visual Studio 2022（或 2019/2017）含 C++ 工具
- CMake 3.15+
- Rust 1.70+

**驗證安裝：**
```bash
# 驗證 Rust
rustc --version
cargo --version

# 驗證 CMake
cmake --version

# 驗證 Visual Studio
"%ProgramFiles%\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
```

### 2️⃣ 編譯 YARA C 庫

```powershell
# 進入項目目錄
cd rust_antivirus

# 運行編譯腳本（自動 CMake + MSVC）
.\build_yara.ps1 -Architecture x64 -VSVersion 2022 -Configuration Release

# 編譯成功後檢查輸出
dir third_party\yara\lib\x64\Release\yara.lib
dir third_party\yara\include\yara\yara.h
```

**預期輸出：**
```
third_party\yara\lib\x64\Release\yara.lib (2-3 MB)
third_party\yara\include\yara\yara.h
third_party\yara\include\yara\types.h
...（其他頭文件）
```

### 3️⃣ 編譯 Rust 程序

```bash
# 清潔編譯
cargo clean
cargo build --release

# 或帶詳細輸出
RUST_LOG=info cargo build --release 2>&1 | tee build.log

# 編譯完成後檢查
ls -la target\release\*.exe
```

**預期輸出文件：**
```
target\release\wenle-antivirus.exe (主程序)
target\release\file-monitor.exe
target\release\memory-monitor.exe
target\release\yara_scan_example.exe
```

### 4️⃣ 測試程序

```bash
# 測試 YARA 掃描示例
cargo run --bin yara_scan_example --release

# 測試主程序（需要 GUI 環境）
cargo run --release

# 或直接運行編譯好的文件
.\target\release\yara_scan_example.exe
.\target\release\wenle-antivirus.exe
```

## 常見問題解決

### 編譯錯誤

**❌ error: linker `link.exe` not found**
```
解決：安裝 Visual Studio C++ 工具或運行 vcvars64.bat
"%ProgramFiles%\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
```

**❌ CMake Error: Visual Studio 版本不匹配**
```
解決：指定正確的 VS 版本
.\build_yara.ps1 -VSVersion 2022
```

**❌ error LNK2001: unresolved external symbol yr_initialize**
```
解決：確保 yara.lib 已編譯且在正確位置
檢查：third_party\yara\lib\x64\Release\yara.lib 是否存在
重新運行：.\build_yara.ps1
```

**❌ error[E0425]: cannot find module `yara_sys` in scope**
```
解決：確保所有模塊在 main.rs 中正確聲明
檢查 src/main.rs 的 mod 聲明
```

### 運行時錯誤

**❌ thread 'main' panicked at 'YARA initialization failed'**
```
解決：
1. 檢查 YARA 庫是否已正確編譯
2. 確保 build.rs 正確設置了連結
3. 重新編譯：cargo clean && cargo build --release
```

**❌ Failed to load YARA rules: Configuration/anti.yarac**
```
解決：
1. 檢查文件路徑：Configuration/anti.yarac
2. 檢查文件大小（應為 27.4MB）
3. 檢查文件讀取權限
4. 考慮使用絕對路徑
```

**❌ thread 'main' panicked at 'Cannot open process'**
```
解決：
1. 以管理員身份運行程序
2. 檢查進程權限
3. 在 Windows Defender 中排除此程序
```

## 進階配置

### 自定義規則加載
在 `yara_integration.rs` 中修改規則路徑：
```rust
const RULES_PATH: &str = "Configuration/anti.yarac";
// 或使用環境變量
let rules_path = std::env::var("YARA_RULES").unwrap_or_else(|_| "Configuration/anti.yarac".to_string());
```

### 自定義掃描配置
在 `config/mod.rs` 中設置：
```rust
pub scan_timeout_ms: 5000,           // 掃描超時（毫秒）
pub memory_chunk_size: 4 * 1024 * 1024, // 記憶體分片大小
pub max_file_size: 500 * 1024 * 1024,   // 最大掃描文件
```

### 自定義隔離路徑
在程序啟動時設置：
```rust
let quarantine_dir = std::path::PathBuf::from("C:\\ProgramData\\Quarantine");
let quarantine = QuarantineManager::new(quarantine_dir)?;
```
